# Product

SideQuest prepares CS students for real engineering work.

## How it works

- Students level up by completing tickets in simulated company codebases using the real workflow: branch → PR → hidden tests → AI code review → fix → pass → XP.
- At Level 6 they unlock a paid, first-come-first-serve job marketplace.

## Context

- Today is an 8-hour hackathon build.

## Priorities

1. The demo works end to end.
2. The architecture is clean enough to scale later.
3. Every mock is clearly labeled.
